## Что это

«Круг двунадесятых праздников» — интерактивный годовой круг: кольца сезонов, месяцев и дней,
на кольце дней отмечены 12 двунадесятых праздников, Пасха, посты (закрашенные дни) и начала постов (пины).
Наведение или тап по маркеру показывает описание; клик закрепляет выбор. Есть переключатель года.

- Сайт: https://inkosarev.github.io/krug-prazdnikov/ (GitHub Pages, публичный)
- Репозиторий: https://github.com/inkosarev/krug-prazdnikov, ветка `main`, раздача из корня
- Копия для себя: `~/Документы/krug-prazdnikov.html` — при правках держать в синхроне с `index.html` или спросить
- Первоначально сделан как артефакт claude.ai (https://claude.ai/artifact/FiBcULZqVjPv28XAwCPsw9, приватный).
  Источник истины теперь `index.html` в этом репозитории; артефакт сам не обновляется.

## Структура

Один самодостаточный файл `index.html`: `<style>` + разметка + `<script>`, без сборки и зависимостей.
Внешнее — только Google Fonts (Old Standard TT — заголовки и даты, PT Sans — текст); без сети фолбэк на системные.
Иконка сайта встроена data-URI SVG в `<head>` (иначе 404 на `/favicon.ico`).

### Данные (в `<script>`)
- `FEASTS` — 12 праздников + Пасха: `id`, `kind` (`lord` Господский / `theotokos` Богородичный / `pascha`),
  `fixed: [месяц 0-11, день]` для непереходящих или `offset` в днях от Пасхи, `name`, `short`, `aka`, `desc`.
- `FASTS` — Великий (Пасха −48…−1), Петров (Пасха +57 … 11 июля), Успенский (14–27 авг),
  Рождественский (28 ноя … 6 янв следующего года), однодневные: Крещенский сочельник, Усекновение, Воздвижение.
- Даты — по новому стилю, как в РПЦ. Старый стиль = −13 дней (верно для 1901–2099, год ограничен этим диапазоном).
- `orthodoxEaster(y)` — алгоритм Меёса для юлианской Пасхи + 13 дней. Контроль: 2025 → 20 апреля, 2026 → 12 апреля.
- `computeFasts(y)` берёт отрезки годов y−1 и y: хвост Рождественского поста прошлого года заходит в январь.
- Все даты — UTC-метки (`Date.UTC`), чтобы не ловить сдвиги часовых поясов.

### Отрисовка
- SVG `viewBox 0 0 900 900`, центр `C = 450`, 1 января наверху, по часовой. Всё рисует `draw()` из JS.
- Два режима геометрии в `GEOMETRY`: `full` и `compact` (толще кольца, крупнее маркеры, месяцы сокращённо
  «янв», без чисел дней и мелких делений, линии «сегодня»/новолетия только по кольцу дней).
- Компактный режим: круг `< 420px` **и** (окно `< 640px` **или** сенсорный экран `pointer: coarse`).
  С мышью от 640px — всегда полный, даже в невысоком окне. Пересчёт — `ResizeObserver` на `.wheel` + `resize` окна.
- Близкие маркеры разводятся по двум орбитам (`gapDays`: 3 дня в полном, 6 в компактном).
- Центр круга: полный — тип, название, дата, день недели/ст. ст.; полный < 480px — только название и дата;
  компактный — только «21 сен».
- Выбор: `state.selected` — id праздника или `fast:<id>` для поста; `preview`/`previewFast` — наведение,
  `restore` — возврат к выбранному.

### Раскладка (брейкпоинты)
| Ширина | Раскладка |
|---|---|
| < 640 | одна колонка; год и легенда под кругом, легенда сеткой в 2 колонки; блок описания без фикс. высоты |
| 640–1023 | круг сверху, описание на всю ширину (высота 320), списки праздников и постов в 2 колонки |
| 1024–1279 | круг слева (sticky), правая колонка 340px |
| ≥ 1280 | правая колонка 360–480px, страница до 1680px |

- Когда колонка круга ≥ 560px (`@container col`), переключатель года — в левом верхнем углу, легенда — в нижних углах.
- На десктопе круг не меньше 540px; если окно ниже 580px — sticky отключается (иначе низ круга не виден).
- Блок описания на десктопе фиксированной высоты 400px с внутренней прокруткой.

### Оформление
Цвета — токены на `:root`, тёмная тема через `prefers-color-scheme` и `[data-theme]`.
Кнопка `#theme-toggle` в ряду года: авто → светлая → тёмная, выбор в `localStorage.theme`;
ранний скрипт в `<head>` ставит `data-theme` до стилей (без мигания). Цвета SVG — CSS-переменные, перерисовка не нужна.
Господские — золото `--gold`, Богородичные — синий `--lapis`, Пасха — киноварь `--cinnabar`, посты — фиолетовый `--fast`.

## Проверка после каждой правки — обязательно

После любой правки открыть страницу в Playwright MCP и посмотреть скриншоты, прежде чем докладывать или пушить.
Пользователь просил это явно — публиковать вслепую нельзя.

1. `file://` в Playwright MCP заблокирован — раздать локально:
   `python3 -m http.server 8765 --bind 127.0.0.1` из этой папки (в фоне), открыть `http://127.0.0.1:8765/`.
2. Смотреть минимум: 1366×768, 1024×768, 390×844, 360×640; при правках раскладки — ещё 1920×1080, 768×1024, 844×390.
3. Менять размер окна **на ходу без перезагрузки** (`browser_run_code_unsafe` + `page.setViewportSize` в цикле,
   снимать `wheel` ширину и класс `compact`) — так ловятся баги режимов и высоты окна.
4. Проверить наведение/клик по маркеру (`.feast[data-id="pascha"] .tap`, `.pin[data-fast="great-lent"] .tap`),
   тёмную тему (`browser_emulate_media`), консоль без ошибок.
5. После — остановить сервер и удалить `.playwright-mcp/` (туда MCP кладёт скриншоты и логи).

## Пожелания пользователя по дизайну (история правок)
- Заголовка и вводного текста нет — круг сразу вверху страницы.
- Круг должен быть виден целиком; на десктопе от 1024px — большой полный круг.
- На мобилке в центре круга только число и сокращённый месяц; легенда ровной сеткой.
- Посты — закрашенные дни + пины в начале многодневных постов с описанием.
