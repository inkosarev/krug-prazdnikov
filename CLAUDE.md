# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Инструкции для Claude Code по работе с этим проектом. Отвечать и писать комментарии — по-русски.
Сборки, линтера и тестов нет — проверка только глазами в браузере (раздел «Проверка» ниже).

## Что это

«Круг двунадесятых праздников» — интерактивный годовой круг: кольца сезонов, месяцев и дней,
на кольце дней отмечены 12 двунадесятых праздников, Пасха, посты (закрашенные дни) и начала постов (пины).
Всё выбирается только кликом/тапом (наведение ничего не показывает — по просьбе пользователя, как на телефоне). Есть переключатель года.

- Сайт: https://inkosarev.github.io/krug-prazdnikov/ (GitHub Pages, публичный)
- Репозиторий: https://github.com/inkosarev/krug-prazdnikov, ветка `main`, раздача из корня
- Копия для себя: `~/Документы/krug-prazdnikov.html` — при правках держать в синхроне с `index.html` или спросить
- Первоначально сделан как артефакт claude.ai (https://claude.ai/artifact/FiBcULZqVjPv28XAwCPsw9, приватный).
  Источник истины теперь `index.html` в этом репозитории; артефакт сам не обновляется.

## Структура

Основное — один файл `index.html`: `<style>` + разметка + `<script>`, без сборки и зависимостей.
Внешнее — только Google Fonts (Old Standard TT — заголовки и даты, PT Sans — текст); без сети фолбэк на системные.
Иконка сайта — восьмиконечный православный крест, встроена data-URI SVG в `<head>` (иначе 404 на `/favicon.ico`);
внутри `<style>` с `prefers-color-scheme`: светлая — `#a4761b`, тёмная — `#d8ae57`. Подножие: поднят правый от Распятого
(левый для смотрящего) конец.

PWA — рядом с `index.html` лежат:
- `manifest.webmanifest` — пути относительные (сайт живёт в `/krug-prazdnikov/`), `display: standalone`.
- `sw.js` — service worker: страница сначала из сети, без сети — из кэша; шрифты и иконки — сначала из кэша.
  При изменении списка предзагрузки или стратегии поднять `VERSION` (старые кэши удаляются при активации).
- `icons/` — PNG 192/512 (512 также maskable, рисунок в безопасной зоне) и `apple-touch-icon.png` 180:
  тот же крест цвета `--gold` тёмной темы на `#10151f`. Генерирует `python3 icons/make-icons.py icons` (PIL);
  после перегенерации поднять `VERSION` в `sw.js` — иконки отдаются из кэша.
- Кнопка `#install` в ряду года: скрыта, пока браузер не пришлёт `beforeinstallprompt` (Chrome/Edge/Android — вызывает
  системный диалог) или на iOS (событий нет — открывает `#install-help` с инструкцией «Поделиться → На экран „Домой“»).
  В установленном приложении (`display-mode: standalone`) не показывается. В headless Chromium событие приходит само —
  признак, что критерии установки выполнены; в консоли при этом info «Banner not shown: …preventDefault()» — это норма.
- `<meta name="theme-color">` для светлой и тёмной темы; `applyTheme()` переписывает их по ручному выбору темы.

### Данные (в `<script>`)
- `FEASTS` — 12 праздников + Пасха: `id`, `kind` (`lord` Господский / `theotokos` Богородичный / `pascha`),
  `fixed: [месяц 0-11, день]` для непереходящих или `offset` в днях от Пасхи, `name`, `short`, `aka`, `desc`.
- `FASTS` — Великий (Пасха −48…−1), Петров (Пасха +57 … 11 июля), Успенский (14–27 авг),
  Рождественский (28 ноя … 6 янв следующего года), однодневные: Крещенский сочельник, Усекновение, Воздвижение.
- Даты — по новому стилю, как в РПЦ. Старый стиль = −13 дней (верно для 1901–2099, год ограничен этим диапазоном).
- `orthodoxEaster(y)` — алгоритм Меёса для юлианской Пасхи + 13 дней. Контроль: 2025 → 20 апреля, 2026 → 12 апреля.
- `computeFasts(y)` берёт отрезки годов y−1 и y: хвост Рождественского поста прошлого года заходит в январь.
- `SOLAR` — 4 события (равноденствия, солнцестояния): подписи и описания. Момент считает `solarEvents(y)` —
  Меёс, гл. 27 (две таблицы: до и после 2000 г., 24 периодических члена) минус ΔT по таблице `DELTA_T`.
  Дата — по Москве (UTC+3), время — `mskTime()`. Контроль 2025: 20 мар 12:01, 21 июн 05:42, 22 сен 21:19, 21 дек 18:03 мск.
- `moonPhases(y)` — новолуния и полнолуния года (Меёс, гл. 49: `lunation(k)`, k целое — новолуние, +0.5 — полнолуние,
  `MOON_TERMS` + `MOON_PLANETARY` + ΔT), дата по Москве; `.prevNew` — последнее новолуние до года.
  `moonAge(t)` — растущая/убывающая и % освещённости (приближённо). Контроль: полнолуние 3 мар 2026 11:38 UTC,
  новолуние 17 фев 2026 12:01 UTC.
- `LAYERS` — слои, которые можно скрыть (`feasts`, `fasts`, `moon`, `sun`); чекбоксы в `#layers` строятся из него.
  Состояние — `state.layers` в `localStorage.layers`, проверка — `on(id)`. `draw()` пропускает скрытые слои
  (орбиты пересчитываются), разделы списков получают `hidden`, пункты легенды с `data-layer` — класс `.off`.
  Новый индикатор: строка в `LAYERS` + ветка в `draw()` + `isVisible()`/`defaultSelection()`.
- Все даты — UTC-метки (`Date.UTC`), чтобы не ловить сдвиги часовых поясов.

### Отрисовка
- SVG `viewBox 0 0 900 900`, центр `C = 450`, 1 января наверху, по часовой. Всё рисует `draw()` из JS.
- Два режима геометрии в `GEOMETRY`: `full` и `compact` (толще кольца, крупнее маркеры, месяцы сокращённо
  «янв», без чисел дней и мелких делений, линия новолетия только по кольцу дней; линия «сегодня» — как в полном,
  от внутреннего края сезонов: `todayFrom`).
- Компактный режим: круг `< 420px` **и** (окно `< 640px` **или** сенсорный экран `pointer: coarse`).
  С мышью от 640px — всегда полный, даже в невысоком окне. Пересчёт — `ResizeObserver` на `.wheel` + `resize` окна.
- Близкие маркеры разводятся по двум орбитам (`gapDays`: 3 дня в полном, 6 в компактном).
- Центр круга: полный — тип, название, дата, день недели/ст. ст.; полный < 480px — только название и дата;
  компактный — «21 сен» и точки событий дня.
- Выбор: `state.selected` — id праздника, `fast:<id>` для поста, `sun:<id>` для солнцестояния или `day:<UTC-метка>`
  для дня (`showDay()` — центр и описание дня; луна в этот день показывается карточкой дня, не отдельным событием —
  вариант «как праздник» пользователю не понравился). Клик по дню (`.hit`) выбирает событие этого дня через `keyForDay(t)`
  (праздник → начало поста → солнцестояние), иначе `day:<t>`; клик по кружку луны — всегда `day:<t>`.
  Курсор `g.day-cursor` (`placeCursor()`, вызывается из `show()`) — как линия «сегодня», шарик у внутреннего конца,
  продолжает спицу выбранного маркера; цвет по `cursorTarget(key).cls` (lord/theotokos/pascha/fast/sun/moon, иначе `--focus`).
  В центре и в описании выбранного события — остальные видимые события того же дня (`otherEvents`/`alsoHtml`,
  строка «Также»). Выключили слой выбранного события — выбор остаётся на его дне (`keyForDay` по `cursorTarget`);
  включили слой обратно, а выбран `day:<t>` — снова выбирается событие этого дня.
  У самого `#wheel` рамка фокуса отключена — Chrome фокусирует svg по клику в пустое место;
  `preview`/`previewFast`/`previewSun` — показ отметки (вызываются через `show()`), `restore` — перерисовать выбранное. Если выбранное скрыто —
  `defaultSelection()` (ближайший праздник, без праздников — ближайшая видимая отметка); всё скрыто — `null`, `showEmpty()`.
- Луна — дорожка `G.moonTrack` между месяцами и днями: при включённом слое кольцо месяцев кончается у
  `moonTrack[0] − 2`, кружки `.moon.new`/`.moon.full` стоят в момент фазы, без событий мыши — зоны `.hit` дней
  начинаются от дорожки. Кружки — `g.moon-mark` (`data-t`), клик выбирает день `day:<t>`.
- В центре полного круга у дня — значок фазы `moonIcon(t)` (серп/половина/диск по освещённости) и `moonText(t)`.
  В центре компактного — дата и цветные точки событий дня `dayEvents(t)` (праздник, пост, солнцестояние, фаза).
- Солнцестояния — маркер `g.sun` («солнышко», `data-sun`) на тех же орбитах, что праздники и пины.

### Раскладка (брейкпоинты)
| Ширина | Раскладка |
|---|---|
| < 640 | одна колонка; год и легенда под кругом, легенда сеткой в 2 колонки; блок описания без фикс. высоты |
| 640–1023 | круг сверху, описание на всю ширину (высота 320), списки праздников и постов в 2 колонки |
| 1024–1279 | круг слева (sticky), правая колонка 340px |
| ≥ 1280 | правая колонка 360–480px, страница до 1680px |

- Когда колонка круга ≥ 560px (`@container col`), переключатель года — в левом верхнем углу (блок 190px, две строки),
  легенда — в нижних углах.
- Клик по году (`#year-label`) открывает `#year-picker`: сетка 4×3 — десятилетие и по году с краёв, листание ‹ ›,
  стрелки/PageUp/PageDown/Esc, закрытие кликом мимо. В углу — от левого края, в узкой колонке — по центру.
- На десктопе круг не меньше 540px; если окно ниже 580px — sticky отключается (иначе низ круга не виден).
- Блок описания на десктопе фиксированной высоты 400px с внутренней прокруткой.

### Оформление
Подсказки: у кнопок года/«Сегодня»/темы/установки — `title` и `aria-label`, у переключателей слоёв — `title` из `LAYERS[].hint`,
у кружков луны — `<title>`. У `#wheel` `role="group"` (не `img` — иначе маркеры-кнопки скрыты от диктора).
Цвета — токены на `:root`, тёмная тема через `prefers-color-scheme` и `[data-theme]`.
Кнопка `#theme-toggle` в ряду года: авто → светлая → тёмная, выбор в `localStorage.theme`;
ранний скрипт в `<head>` ставит `data-theme` до стилей (без мигания). Цвета SVG — CSS-переменные, перерисовка не нужна.
Господские — золото `--gold`, Богородичные — синий `--lapis`, Пасха — киноварь `--cinnabar`, посты — фиолетовый `--fast`,
солнцестояния — бирюзовый `--sun`, луна — `--moon` (обводка),
`--moon-new`/`--moon-full` (заливки: новолуние тёмное, полнолуние светлое в обеих темах). Переключатели слоёв — блок `.layers` первым в правой колонке.

## Проверка после каждой правки — обязательно

После любой правки открыть страницу в Playwright MCP и посмотреть скриншоты, прежде чем докладывать или пушить.
Пользователь просил это явно — публиковать вслепую нельзя.

1. `file://` в Playwright MCP заблокирован — раздать локально:
   `python3 -m http.server 8765 --bind 127.0.0.1` из этой папки (в фоне), открыть `http://127.0.0.1:8765/`.
2. Смотреть минимум: 1366×768, 1024×768, 390×844, 360×640; при правках раскладки — ещё 1920×1080, 768×1024, 844×390.
3. Менять размер окна **на ходу без перезагрузки** (`browser_run_code_unsafe` + `page.setViewportSize` в цикле,
   снимать `wheel` ширину и класс `compact`) — так ловятся баги режимов и высоты окна.
4. Проверить клик по маркеру (наведение ничего не должно менять) (`.feast[data-id="pascha"] .tap`, `.pin[data-fast="great-lent"] .tap`,
   `g.sun[data-sun="june-solstice"] .tap`), переключатели слоёв (`label:has(input[value=sun])` и т. п.; состояние
   переживает перезагрузку — после проверки включить всё обратно), тёмную тему (`browser_emulate_media`), консоль без ошибок.
5. После — остановить сервер и удалить `.playwright-mcp/` (туда MCP кладёт скриншоты и логи).
   Сервер гасить `fuser -k 8765/tcp`, не `pkill -f "http.server 8765"` — pkill убивает и собственную оболочку.

Расчёты дат (Пасха, посты, солнцестояния) можно сверить без браузера: кусок `<script>` от `const FEASTS`
до `function ang(` выполняется в `node`, если закомментировать строки с `document`/`window`/`localStorage`.

## Пожелания пользователя по дизайну (история правок)
- Заголовка и вводного текста нет — круг сразу вверху страницы.
- Круг должен быть виден целиком; на десктопе от 1024px — большой полный круг.
- На мобилке в центре круга только число и сокращённый месяц; легенда ровной сеткой.
- Посты — закрашенные дни + пины в начале многодневных постов с описанием.
- Никаких предпросмотров по наведению — только клик, и на десктопе тоже.
- Отметки включаются и выключаются чекбоксами сверху правой панели; новые индикаторы — тоже со своим чекбоксом.
- `README.md` — короткое описание для GitHub; при новых возможностях поправить строку «что показывает».
